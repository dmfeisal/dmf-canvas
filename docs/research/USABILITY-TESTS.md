# Usability test protocol

Planned moderated workflow; no results or baseline thresholds are established. Recruit the proposed creator cohort in [validation plan](../product/VALIDATION-PLAN.md), including keyboard users where feasible.

Tasks: import a real permitted board; explain fidelity warnings; edit one supported object; add an explanation; save/reload; embed on an Astro test page; open as visitor and navigate explanations. Include a corrupt file and missing-asset recovery task. Avoid coaching until failure/help is recorded.

Measure task completion, assistance, elapsed minutes, data loss, unexpected conversion, keyboard/focus issues and confidence versus the current workflow. Record browser/version, device, fixture, build and account/host conditions. Proposed gate: no unrecoverable data loss and independent completion of the core journey in repeated sessions. Agree numerical thresholds before testing; do not manufacture passing rates from this plan. Design owns protocol and product owns go/no-go.
