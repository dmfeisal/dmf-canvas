# Validation plan

Propose 5–10 designer/developer creator sessions; no recruitment, interviews or usability results have occurred in this task. Recruit people with a real board and an owned portfolio/blog, rather than only tool enthusiasts.

Discovery: observe current board-to-site workflow, losses and alternatives. Usability: import a permitted real Excalidraw board, inspect loss report, edit, explain, save/reload and embed on a test Astro host. Ask whether an editable interactive artifact improves their actual case study compared with their current workflow.

Record completion, help required, time, import fidelity and objections using [metrics](METRICS.md). Separate prototype limitations from lack of need. Advance when repeated independent sessions demonstrate value and the workflow completes without unrecoverable data loss; revise scope if fidelity dominates or setup blocks most participants. Numeric success thresholds are hypotheses to agree before sessions, not discovered facts.

No billing build until willingness-to-pay and hosting costs are understood. Product owns go/no-go; design owns session protocol. See [interviews](../research/USER-INTERVIEWS.md) and [usability plan](../research/USABILITY-TESTS.md).
