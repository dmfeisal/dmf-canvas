Canvas embed example

Shift-click to select objects together, then drag or use arrow keys to move the set. Add a sticky note or draw with Pencil. Use Save file to keep a copy.

Keyboard controls and limits

Add a sticky note or local image, or select Text. Transparent images retain their background; imports resize progressively to fit the board limit. Cancel import stops pending work. Select one image to edit its description; Save description or Enter commits, Escape discards, and Undo restores the previous description; drop one PNG, JPEG or WebP up to 10 MiB/16 megapixels. Images support proportional corners, rotation, locks, layers, Duplicate, Delete, Undo and board files. Drag empty canvas space to select intersecting objects; Shift-drag adds to the selection. Escape or Tab cancels and restores the previous selection. Shift-click toggles objects. Ctrl/Command A selects every available object on the focused canvas; native editors keep Select all for text. Select multiple mode toggles clicks; use Tab and Shift+Enter for keyboard selection. Exit the mode to drag selected objects together, or use arrows for a shared move. Multi-selection hides shape handles and paper colors. Double-click an object, or focus it and press Enter/F2, to edit. Enter adds a line. Done, Escape or Ctrl/Command Enter finishes. Arrow keys move objects and operate focused handles. Choose Paper color for a selected note. Each canvas has separate Undo and Redo, including creation. Up to 50 objects can be retained per canvas. Pencil (P) draws with mouse or pen using the selected width and ink. Release creates one Drawing and returns to Select; V or Escape also selects. Interrupted previews are discarded. Drawings share transforms and history. Embed settings apply independently to each canvas. Read-only permits selection, Copy and Save; it blocks user edits and Open. Hidden tools are also unavailable through commands and shortcuts. Changes finish typing, cancel unfinished gestures and preserve history. Settings last for this visit, including Stop/Start. Unsaved changes updates after completed edits; Save file or Open establishes a clean checkpoint. Undo can return to the saved state. Optional local drafts save completed edits on this device after a short delay. Enable them again after reopening to Restore or Discard a previous draft. Restore replaces this canvas. Draft status is separate from file saving. Copy/Paste (Ctrl/Command C/V) transfers unlocked objects between these embeds on this page, preserving groups and relative positions with a bounded 24px offset. It uses a page-local object clipboard; native text editors retain the system clipboard. Paste is one Undo step and rejects selections that cannot fit intact. Group (Ctrl/Command G) keeps selected objects together; Shift with the same shortcut ungroups. Selecting a member selects its group. Enter/F2 or double-click edits a member without dissolving the group; finish restores whole-group selection. Groups share movement, locks, layers, duplication, Undo and board files. Ungroup before arranging. Arrange aligns two or more unlocked objects to their combined visible bounds, or spaces three or more with equal non-negative gaps. Each arrangement is one Undo step; plans outside owner bounds are rejected together. Use Bring forward/Send backward for one layer step, or Bring to front/Send to back for the full stack. Layer actions preserve keyboard order and share Undo/Redo and board files. Lock/Unlock protects selected objects from editing, transforms, duplication and deletion; mixed selections lock together, with one Undo step. Board files keep locks. Delete/Backspace removes whole selections of created objects; authored originals stay protected. Ctrl/Command D duplicates a selection. Each action has one Undo step. Save file downloads a local board; Open file replaces its created objects and starts fresh history. Nothing is uploaded. Stop restores authored content.
